## Что сделано за эти сессии

### 1. Горизонтальное масштабирование бэкенда (Tier 1) — ✅ в коде
- **Redis-сессии** — `src/redis/` (`RedisModule`, `RedisSessionStore`, тесты).
  Env-gated: есть `REDIS_URL` → Redis, нет → in-memory (локальная разработка zero-config).
- **Webhook-режим** в `main.ts` — есть `WEBHOOK_DOMAIN` → webhook поверх HTTP-сервера
  (там же health-эндпоинт), нет → long-polling. `secretPathComponent` стабилен → все
  реплики ставят один URL и не конфликтуют.
- Корректное завершение: `enableShutdownHooks` + `redis.quit()`.
- `ioredis` в зависимостях. Тип-чек и тесты зелёные.

### 2. Готовность к деплою на Railway — ✅ снят Приоритет 1
- `railway.json` (NIXPACKS, `npm run build` / `npm run start:prod`, restart `ON_FAILURE` ×10).
- Webhook-половина Tier 1 — то, что нужно для жизни в облаке (polling + >1 реплика = `409 Conflict`).

### 3. Шаг к TMA-first и $0-хостингу — ✅
- `scripts/set-menu-button.mjs` — один вызов Bot API ставит кнопку «Открыть Табыс» →
  открывает Mini App. Работает, даже когда бот выключен.

### 4. WB-калькулятор — ✅ задеплоен в прод (TMA-репо)
- Frontend-only, ноль хостинга. ⚠️ Ставки WB — плейсхолдеры, заменить реальными WB-KZ.

### 5. Документация — ✅
