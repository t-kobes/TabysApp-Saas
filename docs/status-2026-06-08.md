## TL;DR

**Табыс** — Telegram-платформа сервисов для продавцов маркетплейсов Казахстана (Kaspi, Wildberries, Ozon). Формат: Telegram Mini App (TMA) + бот-консьерж. Стадия: **pre-revenue, ~4 пользователя, готов к первой волне приглашений.**

За серию сессий продукт вырос из одного калькулятора с хардкодом в **мультиинструмент на живых данных и собственной авторизации, целиком за $0/мес**. Сейчас в проде **4 рабочих бесплатных инструмента** (маржа со сравнением Kaspi·WB, валютный, SEO-генератор, история), бот-консьерж, авторизация через Telegram, живые курсы валют и серверный конфиг ставок. Клин — сравнение Kaspi vs WB на одном экране — работает на реальных комиссиях.

Из ~18 заявленных в видении сервисов в проде **3** (≈17%), но бесплатное ядро — функционально полное, и продукт готов звать первых пользователей по модели «бесплатно за честный отзыв».

## 1. Продукт

**Проблема.** Продавцы КЗ торгуют на Kaspi и WB одновременно, но не знают реальную маржу — не учитывают комиссии, логистику, курс закупки. Узнают про минус постфактум.

**Решение.** Telegram → один тап → за 30 секунд видишь реальную прибыль и ROI на каждой площадке и где выгоднее. Без регистрации и установки.

**Дифференциатор.** Единственный в КЗ инструмент со **сравнением маржи Kaspi vs WB в одном экране**. Конкуренты работают с одной площадкой; МойСклад — дорогой ERP.

**Аудитория.** Малые продавцы: оборот 0.5–5 млн ₸/мес, 10–200 SKU, 1–3 площадки, Telegram как основной мессенджер.

**Бизнес-модель.** Free (калькуляторы, сравнение) → Standard 2 490 ₸ → Pro 4 990 ₸. Сейчас всё бесплатно; монетизация только после D7-retention > 20%.

## 3. Что сделано (хронология)

| Этап | Результат |
|---|---|
| Калькулятор маржи | Единый экран: один ввод → Kaspi и WB сразу + вердикт «где выгоднее» |
| Проф. UI | Иконки, футер с дисклеймером и `beta`, поддержка → @Singersh |
| Авторизация | Edge Function `tg-auth`: проверка Telegram `initData` (HMAC) → JWT; приветствие по имени |
| Бот → консьерж | Edge Function webhook: `/start` с кнопками боли + AI-консультация (Gemini), заводит в TMA; старый NestJS ретайрнут |
| История + RLS | Таблицы `margin_calcs` + `interest`, прямой PostgREST с JWT, экран истории |
| Живые курсы | Edge Function `fx-update` тянет курсы **НБ РК**, ежедневный cron; TMA читает live |
| Серверные ставки | Таблица `platform_rates` — комиссии правятся без редеплоя; внесены **реальные ставки WB** |
| Валютный калькулятор | Закуп в CNY/RUB/USD → себестоимость в ₸ по живому курсу → мостик в маржу |
| SEO-генератор | Двуязычные (рус+каз) описания + ключи + советы по карточке через Gemini |

## 4. Что продукт представляет собой сейчас

**4 рабочих бесплатных инструмента в TMA:**
- 📊 **Калькулятор маржи + сравнение Kaspi·WB** — на реальных комиссиях и логистике
- 💱 **Валютный калькулятор** — живой курс НБ РК, мостик в маржу
- ✍️ **SEO-генератор** — двуязычный, + советы по оформлению
- 🕘 **История расчётов** — у каждого своя (RLS)

**Плюс:** бот-консьерж (заводит в приложение), авторизация через Telegram, сбор спроса через Fake Door-плитки, живые данные (курсы + ставки).

### Архитектура (вся live, $0)
| Слой | Решение |
|---|---|
| Frontend (TMA) | React + Vite + TS + Tailwind → Vercel |
| Backend-логика | Supabase Edge Functions (Deno): `tg-auth`, `bot`, `fx-update`, `seo` |
| БД | Supabase Postgres + RLS (по `telegram_id` из JWT) |
| Данные | Курсы — НБ РК (cron); ставки — `platform_rates` (редактируемые) |
| LLM | Google Gemini (бот-консультации, SEO) |
| Прежний NestJS | ретайрнут (код в репо, не запущен) |

Ключевое: **TMA-first** — вся динамика на Supabase, TMA ходит в БД напрямую под RLS. Нет всегда-включённого сервера → $0 и ноль операционки для команды из одного.

### Готовность заявленных сервисов (~18)
✅ в проде · 🚪 Fake Door · ⬜ не начат

- **Финансы:** ✅ Маржа+сравнение · ✅ Валютный · 🚪 Налоговый · ⬜ Дашборд
- **Контент:** ✅ SEO-генератор · 🚪 Ответы на отзывы · ⬜ Рекламные тексты
- **Аналитика:** ⬜ Радар демпинга · 🚪 Поиск ниш · ⬜ Трекер позиций · 🚪 Аналитика спроса
- **Операции:** ⬜ Менеджер отзывов · ⬜ Накладные · ⬜ Excel/1C · ⬜ Этикетки/НТИН
- **Обучение:** ⬜ База знаний · ⬜ Каталог поставщиков · ⬜ Калькулятор старта

**Итог: 3/18 (≈17%) + бонусом история, и сильный фундамент** (авторизация, данные с RLS, воронка, живые курсы/ставки). Бесплатное ядро — функционально полное.

## 5. Что ожидается (дальше)

**Сразу — не код, а аутрич (правило: код 30% / аутрич 70%):**
- **Волна 1:** 10–20 знакомых селлеров лично, «тестируем вместе, нужен честный отзыв». Метрики: активация (сделал расчёт?), возврат **D1/D7**, голоса Fake Door.

**По сигналу из Волны 1 — строим топ-2–3 сервиса:**
- Кандидаты: налоговый калькулятор, ответы на отзывы, поиск ниш, аналитика спроса — что натапают/попросят.

**Отложено осознанно:**
- 🎨 **AI-инфографика** (нано-банана) — модель доступна, но image-генерация требует включить billing в Gemini (free-тариф = 429). Включается одним шагом, когда будет спрос/деньги.
- 🏷️ **НТИН** (Национальный товарный идентификационный номер) — опциональное поле в SEO, по запросу.
- Ozon, наблюдаемость (sentry/alerts), монетизация (после D7 > 20%).

## 6. Риски и ограничения (честно)

- **До-трекшен:** ключевая гипотеза (нужно кросс-сравнение) количественно не подтверждена — Волна 1 это проверит.
- **Логистика WB — приблизительная** (зависит от склада, габаритов, схемы FBO/FBS); в UI есть сноска. Комиссии — реальные (WB Partners). Первоисточник — кабинет WB Partners.
- **Команда из одного человека** — отсюда стратегия «не строить вслепую, тестировать спрос».
- **Ozon не покрыт** (в калькуляторе Kaspi+WB).
